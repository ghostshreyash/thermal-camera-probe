Thermal Camera Test on a Mac

Step-by-step guide for testing the HIKMICRO MiniE thermal camera for the EVITA app

Easiest way to follow this guideOpen it on the Mac itself, in Safari: thermal-camera-probe.vercel.app/mac-guide. Then you can copy each command straight from the page.

Why we need this: the camera sends its raw sensor readings over USB. To show thermal images and temperatures inside EVITA, we need a few samples of these readings taken while the camera points at objects of known temperature. A small script collects them. It only reads information, changes nothing on the Mac and uploads nothing. You send us the files it saves.

Before you start

  • A Mac with a USB-C port
  • The Mac's login password (an administrator account)
  • Internet connection
  • The HIKMICRO MiniE camera
  • A phone with the HIKMICRO Viewer app (for reference readings)
  • A kettle or mug of hot water
  • A plate or glass of cold water or ice
  • About 45 minutes
Office MacsIf the Mac is managed by an IT team and blocks installing software, Part B may not work. In that case tell us before going further.

Part A: Get ready 5 minutes

A1. Open Terminal

  1. Press ⌘ Command + Space. A search bar appears.
  2. Type Terminal and press Return.
  3. A window with a blinking cursor opens. This is where you will paste every command in this guide.
How to run a commandCopy the command from the dark box (select it, ⌘+C), click inside the Terminal window, paste (⌘+V) and press Return. Wait until the cursor comes back before the next command. Keep this Terminal window open until you finish Part C.

A2. Download the test script

Paste this command and press Return. It saves the script into your Downloads folder.

curl -fsSLo ~/Downloads/camera-probe-mac.sh https://thermal-camera-probe.vercel.app/mac

If nothing is printed and the cursor comes back, it worked.

Part B: One-time install 20–40 minutes, only once

The script needs a free tool called ffmpeg to save the camera's raw readings. It is installed with Homebrew, the standard free installer for Mac tools.

B1. Check whether Homebrew is already installed

brew --version
  • If you see something like Homebrew 4.4.0, Homebrew is installed. Skip to B3.
  • If you see command not found: brew, continue with B2.

B2. Install Homebrew

  1. Paste this command and press Return:
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  2. When it shows Password:, type the Mac's login password and press Return.
    Nothing appears while you type the passwordNo dots, no stars. That is normal on Mac. Type it carefully and press Return.
  3. When it shows Press RETURN/ENTER to continue, press Return.
  4. Wait. It may download Apple's "Command Line Tools" first. This can take 10–30 minutes. Do not close the window.
  5. It is finished when you see Installation successful! and the cursor comes back.
  6. Paste this command so Terminal can find Homebrew, and press Return:
    eval "$(/opt/homebrew/bin/brew shellenv 2>/dev/null || /usr/local/bin/brew shellenv)"
    Nothing is printed. That is fine.

B3. Install ffmpeg

brew install ffmpeg

This takes 5–15 minutes and prints a lot of text. When the cursor comes back, check it worked:

ffmpeg -version
ffmpeg version 7.1 Copyright (c) 2000-2024 the FFmpeg developers built with Apple clang ...

The exact version number does not matter. If you see command not found: ffmpeg, paste the command from step B2.6 again, then try once more.

Part C: Run the tests about 5 minutes per test

We need 3 tests, one per object. For each test you take two readings of the same object: first with the script on the Mac, then with the HIKMICRO app on the phone.

TestPoint the camera atTip
1. HotKettle or mug filled with hot waterHot water cools quickly. Do the phone reading right after the Mac.
2. ColdPlate or glass with cold water or iceSame as above.
3. HandAn open palmHold the hand still, about 30 cm from the camera.
Keep the camera steadyHold it (or rest it) about 30 cm from the object so the object fills most of the view. Keep the same distance for the Mac and phone readings.

For each test, follow C1 to C4

C1. Start the script

bash ~/Downloads/camera-probe-mac.sh
Thermal camera probe for macOS (v2). Read-only; changes nothing. Report folder: /Users/yourname/Desktop/thermal-probe-20261114-101500 == Step 1 of 2 == Close the camera maker's app, UNPLUG the thermal camera, then press Enter...

C2. Unplug, then plug in

  1. Unplug the camera from the Mac (and from the phone, if it is there). Press Return.
  2. The script shows:
    == Step 2 of 2 == Now PLUG the camera in, point it at the test object, wait about 5 seconds, then press Enter...
  3. Plug the camera into the Mac, point it at the object, wait 5 seconds, press Return.
  4. If the Mac asks "Allow accessory to connect?", click Allow.

C3. Allow the camera (first test only) and wait

  1. The first time, macOS shows "Terminal" would like to access the camera. Click OK / Allow.
  2. If the script then says The first try did not get a picture ... press Enter to try again, keep the camera pointed at the object and press Return.
  3. Keep the camera still for about 30 seconds until you see the result:
== Result == ... Frame grab: frame.png saved; frames-native.raw saved (... bytes, 10 frames) DONE. Send this file: /Users/yourname/Desktop/thermal-probe-20261114-101500.zip
What mattersThe line starting Frame grab: should say frames-native.raw saved. The rest of the result (the "VERDICT" lines) is for us; you don't need to understand it.

C4. Take the reference reading on the phone

  1. Unplug the camera from the Mac and plug it into the phone.
  2. Open the HIKMICRO Viewer app and point the camera at the same object, from the same distance.
  3. Take a screenshot that shows the temperature (the "Max" value and the colour scale).

Then repeat C1 to C4 for the next object. Each run creates a new thermal-probe-….zip on the Desktop.

Optional: rename the zip files

To avoid mix-ups, rename each zip on the Desktop after its test: click the file once, press Return, type a new name (hot.zip, cold.zip, hand.zip) and press Return.

Part D: Send the files 2 minutes

Send these:

From the Mac DesktopFrom the phone
3 zip files: thermal-probe-….zip (or hot / cold / hand.zip)3 screenshots from the HIKMICRO app

With each pair, write one line saying which object it is, for example: "Hot kettle: hot.zip + screenshot, app showed max 67.3°C".

Please send only the .zip files, not the thermal-probe-… folders next to them. You can leave the folders on the Desktop or delete them afterwards.

If something goes wrong

What you seeWhat to do
No such file or directory when starting the scriptThe script is not in Downloads. Repeat step A2, then try again.
command not found: brewPaste the command from step B2.6, then try again. If it still fails, Homebrew is not installed: do step B2.
Homebrew says the user is not an administrator, or installing is blockedThe Mac account needs admin rights. Use an admin account, or ask IT. If that is not possible, tell us.
The result says NOTE: ffmpeg is not installedDo Part B3, then run the test again.
The result says raw frames NOT saved or could not grab a pictureCamera access is probably blocked. Open System Settings → Privacy & Security → Camera, turn on Terminal, choose "Quit & Reopen" if asked, then run the test again.
VERDICT: INCONCLUSIVE / Camera not identifiedThe Mac did not detect the camera. Plug it directly into the Mac (no hub or adapter), make sure it is unplugged from the phone, and run the test again.
Pressing Return does nothingClick inside the Terminal window first, then press Return.
Anything elseTake a screenshot of the whole Terminal window (⌘+Shift+4, then Space, then click the window) and send it to us. Send any zip files created so far too.

What the script does

  • Reads the list of USB devices and cameras connected to the Mac, and the video formats the thermal camera offers.
  • Takes one picture and ten raw frames (less than a second of video) from the thermal camera.
  • Saves everything into a folder and a zip on the Desktop. Nothing is sent anywhere automatically.
  • Does not change any settings and does not install anything. ffmpeg and Homebrew are installed only by the commands in Part B, which you run yourself.
  • The zip contains: a short text report, the camera's picture and raw frames, and a list of USB devices connected to this Mac.

Removing the tools later (optional): brew uninstall ffmpeg. You can delete the script from Downloads.
