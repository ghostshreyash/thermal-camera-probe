Thermal Camera Probe

Checks whether a plugged-in thermal camera can be read directly by an app, without the maker's own software. Nothing is changed on the camera or the tablet.

Before you start

  1. Close the camera maker's app (e.g. HIKMICRO Viewer) completely — it can hold the camera so nothing else can open it.
  2. Plug the thermal camera into the tablet's USB-C port. If Android asks which app to open, tap Cancel.
  3. Work through steps 1–3 below, then send the report from step 4.

1 This device

2 Cameras the browser can see

Allow camera access when asked. Every camera is listed — the tablet's own front and rear cameras too. Test the one that is not front or back, or test them all.

3 USB details

Opens Chrome's USB device list. Pick the thermal camera if it appears. If the list is empty or the camera is missing, tap Cancel — that result is useful too.

4 Result

Run steps 2 and 3 to get a result.

Send the downloaded report (and the frame images, if any) back to the EVITA team.
