Thermal Camera Test on Windows

Step-by-step guide for testing the HIKMICRO MiniE thermal camera for the EVITA app

Easiest way to follow this guideOpen it on the Windows PC itself, in Chrome or Edge: thermal-camera-probe.vercel.app/windows-guide. Then you can copy each command straight from the page.

Why we need this: the camera sends its raw sensor readings over USB. To show temperatures inside EVITA, we need a few samples of these readings taken while the camera points at objects of known temperature. A small script collects them. It only reads information, changes nothing on the PC and uploads nothing. You send us the files it saves.

Before you start

  • A Windows 10 or 11 PC or laptop with a USB-C port
  • Internet connection
  • The HIKMICRO MiniE camera
  • About 30 minutes
  • A phone with the HIKMICRO Viewer app (for reference readings)
  • A kettle or mug of hot water
  • A plate or glass of cold water or ice
Two rules that save a lot of trouble 1. Never press Ctrl+C while the script is running, even if it looks stuck. It stops on its own; pressing Ctrl+C can jam the camera until it is unplugged.
2. Paste with a right-click inside the PowerShell window. This works everywhere, including over AnyDesk or TeamViewer, where Ctrl+V can misfire.

Part A: Get ready 5 minutes

A1. Open Windows PowerShell

  1. Click Start (or press the ⊞ Windows key) and type powershell.
  2. Click Windows PowerShell. Not "PowerShell 7", not "PowerShell ISE", and no need to "Run as administrator".
  3. A blue or black window with a blinking cursor opens. This is where you will paste every command in this guide.
How to run a commandSelect the command in the dark box and copy it (Ctrl+C, on this page). Then right-click inside the PowerShell window to paste it, and press Enter. Wait until the cursor comes back (a line ending in >) before the next command.

A2. Download the test script

This saves the script into your Downloads folder.

Invoke-WebRequest https://thermal-camera-probe.vercel.app/windows -OutFile "$HOME\Downloads\camera-probe.ps1"

If nothing is printed and the cursor comes back, it worked. A blue progress bar may flash for a moment.

Part B: One-time install 5–10 minutes, only once

The script needs a free tool called ffmpeg to save the camera's raw readings. It is installed with winget, the installer built into Windows 10 and 11.

B1. Install ffmpeg

winget install Gyan.FFmpeg --accept-source-agreements --accept-package-agreements
Found FFmpeg [Gyan.FFmpeg] Version 9.1 Downloading https://github.com/GyanD/codexffmpeg/releases/... ██████████████████████████████ 252 MB / 252 MB ... Path environment variable modified; restart your shell to use the new value. Successfully installed

The download is about 250 MB, so it can take a few minutes. If Windows asks "Do you want to allow this app to make changes?", click Yes.

B2. Close PowerShell and open it again

Close the PowerShell window (the X at the top right), then open a new one as in step A1. The new window is the one that knows where ffmpeg is. Check it:

ffmpeg -version
ffmpeg version 9.1-full_build-www.gyan.dev Copyright (c) 2000-2026 the FFmpeg developers built with gcc ...

The exact version number does not matter. If you see 'ffmpeg' is not recognized, close the window and open a new one once more. If it still fails, do B1 again.

Part C: Run the tests about 3 minutes per test

We need 3 tests, one per object. For each test you take two readings of the same object: first with the script on the PC, then with the HIKMICRO app on the phone.

1. HotKettle or mug filled with hot waterHot water cools quickly. Do the phone reading right after the PC.
2. ColdPlate or glass with cold water or iceSame as above.
3. HandAn open palmHold the hand still, about 30 cm from the camera. Not right against the lens; the hand should not fill the whole view.
Keep the camera steadyHold it (or rest it) about 30 cm from the object, so the object fills most of the view with some background around it. Keep the same distance for the PC and phone readings.

C3. Keep the camera still and wait

The script now reads the camera's formats and saves the frames. Keep the camera pointed at the object, without moving, for up to one minute. Do not press anything.

What mattersOne Frame grab: line should say frames-native.raw saved. A yellow line about 96x322 is expected on Windows; it is not an error. The "Result" lines are for us; you don't need to understand them.

C4. Take the reference reading on the phone

  1. Unplug the camera from the PC and plug it into the phone.
  2. Open the HIKMICRO Viewer app and point the camera at the same object, from the same distance.
  3. Take a screenshot that shows the temperature (the "Max" value and the colour scale).

Then repeat C1 to C4 for the next object. Each run creates a new thermal-probe-….zip on the Desktop. Unplugging and plugging in at the start of every test (C2) is important: it also resets the camera.

Optional: rename the zip files

To avoid mix-ups, rename each zip on the Desktop after its test: click the file once, press F2, type a new name (hot, cold, hand) and press Enter.

Part D: Send the files 2 minutes

Send these:

From the PC's DesktopFrom the phone
3 zip files: thermal-probe-….zip (or hot / cold / hand.zip)3 screenshots from the HIKMICRO app

With each pair, write one line saying which object it is, for example: "Hot kettle: hot.zip + screenshot, app showed max 67.3°C".

Please send only the .zip files, not the thermal-probe-… folders next to them. If the Desktop is synced to OneDrive, the files are still on the Desktop; nothing else changes.

If something goes wrong

What you seeWhat to do
running scripts is disabled on this systemStart the script with the exact command from C1. The -ExecutionPolicy Bypass part allows it for this one run only.
Please run this in Windows PowerShell (powershell.exe), not PowerShell 7You opened PowerShell 7. Close it and open Windows PowerShell (step A1).
Cannot find path ... camera-probe.ps1 or does not existThe script is not in Downloads. Repeat step A2, then try again.
'winget' is not recognizedOpen the Microsoft Store, search for App Installer, install or update it, then open a new PowerShell window and do B1 again. If the Store is blocked (office PCs), tell us.
ffmpeg not installed - skippingClose PowerShell, open a new window, check ffmpeg -version (B2), then run the test again.
No new device appearedThe PC did not see the camera. Unplug it from the phone, plug it straight into the PC (no hub or adapter), listen for the Windows "connected" sound, and run the test again.
No raw frames were saved or capture failedClose any app that may be using a camera (Camera, Teams, Zoom, WhatsApp, the HIKMICRO app). Check Settings → Privacy & security → Camera: turn on Camera access and Let desktop apps access your camera. Then run the test again; the unplug/plug step resets the camera.
Nothing happens for more than 2 minutesDo not press Ctrl+C. Close the window with the X, unplug the camera, wait 5 seconds, plug it back in, open a new PowerShell window and start again from C1.
Pressing Enter does nothingClick inside the PowerShell window first, then press Enter.
Anything elseTake a screenshot of the whole PowerShell window (⊞ Windows+Shift+S) and send it to us. Send any zip files created so far too.

What the script does

  • Reads the list of USB devices and cameras connected to the PC, and the video formats the thermal camera offers.
  • Takes ten raw frames (less than a second of video) and one picture from the thermal camera. Each capture stops itself after 15 seconds, so it cannot hang.
  • Saves everything into a folder and a zip on the Desktop. Nothing is sent anywhere automatically.
  • Does not change any settings and does not install anything. ffmpeg is installed only by the command in Part B, which you run yourself.
  • The zip contains: a short text report, the camera's raw frames and picture, and a list of the USB devices connected to this PC.

Removing the tools later (optional): winget uninstall Gyan.FFmpeg. You can delete the script from Downloads.
